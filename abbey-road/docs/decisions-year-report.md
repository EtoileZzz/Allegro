# 年度 / 月度报告（v0.5.3）决策记录

新增「长按卡底按钮 → 年度 / 月度报告」，并统一统计弹窗的切页高度。

## 一、入口与范围

### D1 长按 520ms 进入报告，三个入口各看各的域
- **结论**：作业卡「作业统计…」→ 作业报告；任务卡「数据分析」→ 打卡报告；
  日程卡「日程总览」→ 日程报告。设置 → 工作面板里那个「作业统计…」同样支持长按。
- **理由**：用户明确要"各进各自的报告"。三个入口都是同一个 `tk-fbtn`，
  加一个 `bindTapHold` 就能统一接线；不统一成一个报告，是为了避免把
  作业完成率和打卡达成率混在一页里互相干扰。

### D2 长按触发后吞掉 click
- **结论**：`bindTapHold` 里 `fired` 标记：长按成功后那次 click 直接 `preventDefault`。
- **理由**：按钮原本的 click 是开统计弹窗，不吞掉会出现"报告刚开就被统计盖住"。

### D3 报告只有「年度 / 月度」两档，默认年度
- **结论**：长按默认落在年度；月度里用左右箭头切月。
- **理由**：长按 = 想看大局；周报与现有「趋势」页重叠。

### D4 数据范围 = 第一笔记录 → 今天
- **结论**：`reportFirstDay(domain)` 找该域最早一条记录，不足一年就画实际天数。
- **理由**：用户选择"从第一笔记录算到今天"，不留空年份；也避免旧数据不足一年时
  大片空白。

## 二、口径

### D5 作业：布置完成率 / 按时完成率 / 平均用时
- **结论**：
  - 布置完成率 = 期间布置且已完成 ÷ 期间布置条数（分母唯一，不会 >100%）
  - 按时完成率 = 有截止日的条目里「完成日 ≤ 截止日」或「已过期未做」的占比
  - 平均用时 = mean(完成日 − 布置日)，只统计两者都有的条目
- **理由**：与现有 `taskStats()` 的 84 天口径一致，只换窗口；用户确认完成率用
  "布置完成率"这一种，不并列第二套。

### D6 任务：计划达成率按「条目」算，不按天数
- **结论**：达成率 = 期间打卡次数之和 ÷ 期间计划条目数之和；计划条目数 =
  每天 `todoRequired()` 累加（每天型 = 天数×次数，指定星期 = 命中星期数×次数，
  每 N 天 = 命中间隔数，每周型 = 周数×次数）。无计划任务（unlimited）不进分母。
- **理由**：用户点名"以条目、计划计算而非天数"。按天数会把"每周 3 次"算成每天欠一次。

### D7 任务报告只统计次数，不展示量（页/小时）
- **结论**：不汇总 `amount`。
- **理由**：用户确认；跨单位相加没有意义，按单位分开列又会把报告撑爆。

### D8 KPI 6 格（2×3）
- **结论**：年度/月度都是 6 格；首个为累计数，其余为比率/节奏指标。
- **理由**：用户确认 6 格；一屏能看全，不用滚。

## 三、版式

### D9 年度热力图按季度竖排（3 个月一块）
- **结论**：范围里的月份按 3 个一组切块，每块一块热力图 + 当月合计。
- **理由**：53 周横排手机放不下；竖向滚动是已有交互。范围不足 3 个月时只有一块。

### D10 未来日子留白、今天描边、月份标签只在范围内出现
- **结论**：热力图与 12 周贡献图同一套规则；月份标签只在该列落在范围内时打，
  避免把块前一个月的「3 月」也写出来。
- **理由**：和上一轮修好的作业热力图保持一致；标签错位是实测发现的问题。

### D11 日程报告 = 上课节数 + 事件数，没有完成率
- **结论**：上课节数用 `AR.Schedule.dayItems()` 逐日展开（按日期找所属学期），
  事件用 `eventsBetween`。
- **理由**：日程没有"完成"概念；复用课表口径，数字不会和「今日」页打架。

## 四、交互与尺寸

### D12 统计弹窗固定高度（`modal-fixed`）
- **结论**：任务数据分析 / 作业统计 / 日程总览 / 报告都加 `modal-fixed`：
  `height: min(86vh, 780px)`，只有内容区滚动。
- **理由**：用户要求"同一界面内切页签窗口大小不要变"；不同弹窗可以保持各自的宽度
  （日程总览仍是 wide，另两个仍是普通宽度）。
- **实测**：任务数据分析四个页签切换均 726px；作业统计切页 726px。

### D13 任务数据分析-总览加全局热力图
- **结论**：KPI 之后插入「最近 12 周 · 所有任务合计」，一格 = 当天所有任务打卡次数，
  按 12 周内非零日的 p25/p50/p75 分四档，今天描边、未来留白。
- **理由**：用户要求；与单任务贡献图同一套观感，但用分位而不是"目标比例"，
  因为跨任务没有统一目标。

## 五、不做 / 待定

- 不做周报（与「趋势」页重叠）。
- 报告里不做筛选器（筛选交回记录页）。
- 待定：月度报告是否加"当月按周"细分；日程报告是否加"每门课节数排行"。
- 已知限制：`doneAt` 缺失的老作业不计入"完成日"统计（报告只按有完成日期的算）。
